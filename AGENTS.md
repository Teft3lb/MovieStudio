# MovieStudio

- Единственный рабочий проект находится в `D:/Develop/MovieStudio`. В Godot открывайте `D:/Develop/MovieStudio/project.godot`.
- Единственная рабочая ветка — `main`. Работайте в существующей корневой копии. Вложенные копии проекта и новые рабочие ветки запрещены.
- Перед каждой задачей выполните `git rev-parse --show-toplevel`, `git branch --show-current` и `git status --short --branch`. Убедитесь, что корень и ветка соответствуют этим правилам. Сохраняйте локальные изменения пользователя.
- По завершении каждого этапа проверьте diff и запустите связанные тесты. Для графики и интерфейса также проверьте игру с активным рендерингом в Godot 4.7.2. Включайте в Git нужные ресурсы, Blender-исходники, экспорт, настройки импорта и валидные UID.
- При правках мебели проверяйте масштаб, проходы, посадку и точки взаимодействия. При правках сотрудников сверяйте сохранённую внешность, риг, позы и костюмы. Команды визуальной проверки и карта ресурсов есть в [Visual Overhaul v3](docs/architecture/visual_overhaul_v3.md).
- После успешной проверки создайте локальный коммит, выполните `git fetch origin`, безопасно интегрируйте новые изменения `origin/main` и перепроверьте затронутый код. Публикуйте обычным `git push origin main`.
- Сверьте полный SHA из `git rev-parse HEAD` с `git ls-remote origin refs/heads/main`. Этап считается завершённым после публикации необходимых файлов и совпадения SHA.
- Force push, `git reset --hard`, `git clean -fd` и удаление пользовательских наработок запрещены.

Команды запуска и проверки описаны в [README](README.md) и [Git workflow](docs/architecture/git_workflow.md).
